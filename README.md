# amazon

Серверная часть интернет-магазина на NestJS и Prisma. Учебный проект 2023 года.

## О приложении

API работает на PostgreSQL. Пользователь регистрируется, входит и получает пару токенов: access и refresh. Токен доступа обновляется по refresh-токену, пароли хранятся в виде хешей argon2. Защищённые маршруты открывают профиль пользователя, позволяют изменить его данные и добавить товар в избранное или убрать его оттуда.

В схеме базы описаны товары с категориями и картинками, отзывы с оценками, заказы со статусами и позициями. Для наполнения базы есть сид на Faker: он создаёт случайные товары, категории и отзывы.

Проект не закончен: API есть только для входа и профиля, а товары, заказы и отзывы пока существуют лишь в схеме.

## Маршруты

| Метод | Адрес | Что делает |
|---|---|---|
| POST | `/api/auth/register` | регистрация |
| POST | `/api/auth/login` | вход |
| POST | `/api/auth/login/accesss-token` | новая пара токенов по refresh-токену |
| GET | `/api/users/profile` | профиль |
| PUT | `/api/users/profile` | изменение профиля |
| PATCH | `/api/users/profile/favorites/{productId}` | добавить товар в избранное или убрать |

## Как запустить

Потребуются Git, Node.js 18 или новее и PostgreSQL.

```bash
git clone https://github.com/vleypi/amazon.git
cd amazon
npm install
cd backend-amazon
npm install
```

В `backend-amazon/.env` нужно задать адрес базы и секрет для токенов:

```
DATABASE_URL=postgresql://user:password@localhost:5432/amazon
JWT_SECRET=секрет
```

Затем создать таблицы и запустить сервер:

```bash
npx prisma db push
npm run start:dev
```

После запуска API доступно по адресу http://localhost:4200/api. Сид запускается командой `npm run seed`, перед ним нужно зарегистрировать хотя бы одного пользователя: отзывы привязываются к пользователю с `id` 1.

## Структура

```
amazon/
├── backend-amazon/
│   ├── prisma/schema.prisma   схема базы: пользователи, товары, категории, отзывы, заказы
│   ├── seeder/seed.ts         наполнение базы случайными товарами
│   └── src/
│       ├── auth/              регистрация, вход, токены
│       ├── user/              профиль и избранное
│       ├── config/            настройки JWT
│       ├── utils/             slug и случайные числа
│       └── main.ts            запуск, префикс /api, порт 4200
└── package.json               зависимости авторизации
```
